# Единая устойчивая навигация сессий

Owner CONTROL-UNIFIED-SESSION-NAVIGATOR. Пользователь принял схему и deployment12.10. Base web26.

## Результат
На странице сессий один навигационный список вместо трёх видимых списков pinned/participation/project. Desktop>=1024 sidebar с собственной прокруткой и чат рядом. Mobile/tablet<1024 отдельная панель выбора поверх страницы; после выбора сессии закрывается, чат занимает ширину. Перед выбором панель открыта. Из чата открывается кнопкой «Сессии · ждут ответа N». Чат/черновик/прокрутка сохраняются при открытии/закрытии панели.

## Контракт (INV-USN-01..08)
