Основание: прямой запрос dwl 27.10.2026. Parent CONTROL-DEEPSEEK-LIMITS-20261026 (Root, web scope) не меняется; этот child — только бот. Наблюдаемое поведение /limits, кнопки Лимиты и периодического сообщения формируется общей render(envelope, now=None) ai-agent-limits-digest.

INV-DSBOT-01: Баланс direct DeepSeek API — денежная величина с валютой; не процент подписки, не окно и не время reset. Не подменять данными OpenRouter. Существующие провайдеры/дедуп/алерты не меняются.
INV-DSBOT-02: GET https://api.deepseek.com/user/balance с Bearer DEEPSEEK_API_KEY. Никаких model/completions запросов. Использовать имеющийся http_get(url,headers,PROXY) и TIMEOUT, существующий proxy не менять. Ключ читать при вызове только из переменной окружения DEEPSEEK_API_KEY; не выводить/кэшировать/писать в DTO/logs. Отсутствие/пустой ключ — not_configured, не сетевой запрос.
INV-DSBOT-03: Ответ API object с is_available exact bool и непустым balance_infos list. Каждый элемент содержит currency CNY/USD, total_balance/granted_balance/topped_up_balance decimal strings. Числа конечные, не bool/float/NaN/Infinity; currency уникальны; malformed весь ответ => error, не ноль. Можно показывать total только, остальные два поля нужны для валидации; не вычислять расход из текущего остатка, не суммировать разные валюты.
INV-DSBOT-04: build_deepseek(now=None) -> closed public dict status=ok|not_configured|error, source=DeepSeek API, captured_at=ISO UTC now. ok: is_available bool, balances=[{currency,total_balance,granted_balance,topped_up_balance}] strings. error: безопасный reason только фиксированная категория HTTP/сеть/неожиданный ответ, никакого raw API/body/exceptionargs. no-key: reason нет ключа API. API ошибки 0/401/403/429/5xx различимы по безопасной категории, no balance fields в error.
INV-DSBOT-05: render существующего envelope добавляет DeepSeek API в общий текст рядом с prepaid блоками; ok: текущий total_balance каждой валюты, время снимка, при is_available false — API недоступен по балансу. not_configured — не настроен; error — данные недоступны + безопасная причина. Старый кэш без deepseek показывает DeepSeek API: нет данных (не нулевой остаток). Снимок deepseek старше AI_AGENT_LIMITS_STALE_MIN (default45) показывает устаревание даже при свежем envelope; не выдавать старое за свежее. Не рендерить сырые непроверенные поля/сырой reason из недоверенного snapshot; максимум whitelist безопасных причин. Балансы Decimal, не float; 2+ знака сохраняются разумно без scientific/HTML инъекции.
INV-DSBOT-06: mode_once использует safe(build_deepseek), сохраняет snapshot.deepseek и общий render для dryrun/notify. Existing digits_signature не включает deepseek, prepaid alert behavior не меняется. Ни дополнительных сообщений, ни платных запросов, ни новых alerts/истории/прогнозов. ## Уточнения до реализации

Денежные строки сохраняют все переданные дробные знаки, без округления/float/scientific. Defensive bound: строка максимум64 ASCII символа, обычная signed-decimal запись; экспоненциальная/не finite/не строковая запись означает error, не ноль. Это правило передано implementer до патча. Source-binding исправление ожидаемой кнопки notify: точный существующий текст «🔄 Обновить»; тело бота/transport не меняются.

Проверка режима once использует реальные safe/build_deepseek/render/mode_once и mocked collectors/cache/clamp/state/alerts/subprocess.run; попадание в cache и notify input проверено, реального Telegram/API не было.
