# Компактная кнопка APP

В шапке сайта ссылка «Андроид» заменена визуальной вторичной кнопкой APP.
Это обычная навигационная ссылка /download/android/, доступная до входа.
После входа она находится рядом с «Выйти» в общей группе справа. Существующая
логика hidden кнопки выхода сохраняется. Группа не разносит действия по всей
ширине. На320px иdesktop элементы не перекрываются и не создают overflow,
цель нажатия44px и клавиатурный фокус сохраняются. Auth/API/APK не входят.

Трассируемость: существующий INV50 browser navigation test; label обновлён по
явному требованию пользователя11.10. Проверка размещения — visual geometry.
