# Новые команды и пути ai-control: веб-компонент

Пользователь требует не только название, но и новые команды/пути. На llm установлен старый web пакет, frontend/broker выключены, enrollment отсутствует по сообщению Mac. Первый этап меняет актуальную инструкцию установки и веб-компонент, чтобы пользователь выполнял команды ai-control-web и получал сервисы и пути ai-control-web. Действующие TASK/core registry/CLI мигрируются отдельно совместимыми этапами; repository rename остаётся кандидатом, не менять его в этой фиче.

Контракт INV-WEB-09 из docs/specs/web.md: новый executable bin/ai-control-web имеет тот же argparse интерфейс init-auth/web/broker, те же зависимости и private-file policy. Legacy bin/claude-control-web продолжает работать, реализация не дублируется. Оба CLI входят scripts.manifest. Новые templates systemd/ai-control-web.service.tmpl и ai-control-web-broker.service.tmpl используют /opt/ai-control-web, /var/lib/ai-control-web, /run/ai-control-web и bin/ai-control-web. Имена legacy templates могут сохраниться как историческая совместимость, но public runbook ведёт на новые. ReadWritePaths и RuntimeDirectory совпадают с новыми auth/socket paths. UID/group claude-panel остаются, broker registry/--bin-dir placeholders не меняются.

Критерии: независимые committed semantic RED для --help новой CLI, executable и manifest; оба templates полные/sandbox/private paths/owner placeholders корректны; installation public runbook использует новый CLI/package/unit paths и явно описывает отключение старых services, сохранение auth+TOTP state до миграции, отказ перезаписать существующее состояние. Existing46 web tests и installer regression GREEN. Миграция живых TASK данных и repository rename не входят; migration installed web без enrollment делегируется agent_bus после accepted SHA.

Деплой не устанавливается из worktree. Secrets/state не выводятся и не передаются через bus. При уже существующем enrollment Mac останавливается и сообщает наличие без содержимого; перенос credentials только локальный с UID/mode preservation, replay state не сбрасывается. Старый пакет оставляется для rollback после отключения старых services, не удаляется автоматически.
