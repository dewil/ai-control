# MADVICE - ручная рекомендация уровня исполнителя

Домен покрывает отдельную команду, которая по явно выбранному публичному
тексту получает от доверенного Jev helper оценку уровня исполнителя и
сохраняет ручную квитанцию в существующей Markdown-задаче.

## Границы

**Входит:** `bin/ai-agent-model-advice`, конфигурация helper и явных
сопоставлений через `CONTROL_JEV_*`, фиксированный файл вопросов рядом с
helper, bounded-вызов helper и fenced JSON-квитанция в задаче.

**Не входит:** автоматический выбор или переключение модели, запуск Codex,
изменения сессий, бота, daemon, разрешений или реестров; поиск текста по
проекту, памяти или задачам; оценка доступности модели. Секреты и политика
допуска к чувствительным задачам остаются вне публичного consumer-кода.

Контракт проверен на Linux с Python 3.11+. Автоматические тесты используют
синтетический локальный helper; живой native Jev smoke и операторский
acceptance выполняются отдельно после проверки развертывания и не запускаются
этой командой или тестами.

## Инварианты

- **INV-MADVICE-01.** В helper уходит только содержимое файла, явно названного
  `--public-text-file`; его размер не больше 16 KiB и 4000 UTF-8 символов.
  Команда не сканирует соседние файлы и не экспортирует задачу или память.
  Довод: текст пересекает внешнюю границу только после явного выбора вызывающего.
- **INV-MADVICE-02.** Результат всегда advisory: команда не запускает
  исполнителя и не меняет модель. `--risk`, `--current-model`, уровень
  `clarify` и отсутствующее сопоставление не дают кандидата. Довод: оценка
  уровня не является подтверждением запуска или отсутствия риска.
- **INV-MADVICE-03.** До успешного stdout квитанция добавляется под `flock`
  только в существующий обычный nonsymlink `.md`-файл; исходные байты и
  режим файла сохраняются. Ошибка записи не возвращает успех. Довод:
  рекомендация должна пережить сессию, не подменяя содержимое задачи.
- **INV-MADVICE-04.** Helper задается абсолютным операторским путем вне
  рабочего дерева; рядом
  проверяется побайтно закрепленный SHA-256 `jev-executor-questions.json`.
  Процесс запускается без shell, с timeout 95 секунд; stderr и свободный
  текст ответа не копируются в квитанцию. Довод: helper и вопросы являются
  операторской границей, а внешний ответ — недоверенные данные.
- **INV-MADVICE-05.** Helper и модели берутся только из allowlist
  `CONTROL_JEV_*`; окружение процесса имеет приоритет над существующим
  `~/.config/ai-control/env`. Нет автоматических дефолтов или новых
  registry/native settings. Довод: наличие команды не должно менять уже
  настроенную модель или сессию.

## Внешний контракт

```text
ai-agent-model-advice --public-text-file PATH --task PATH [--risk]
                          [--current-model SLUG]
```

Успех печатает одно JSON-значение и добавляет то же значение в fenced-блок
`json` в конец задачи. Поля, основанные на helper, ограничены tier enum,
проверенными скалярами и строгим шаблоном `typesafe/jev-*`; причина статична.
Кандидат возможен только для `cheap`, `standard` или `deep`, если оператор
задал соответствующее сопоставление. Повторный запуск команды — новое явное
обращение к helper; квитанция не запускает повтор автоматически.
